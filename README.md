# مركز حملة القرآن

نظام إدارة متكامل لمراكز تحفيظ القرآن الكريم: يدير المراكز والفروع والحلقات والطلاب والمعلمين، ويتابع الحضور والاشتراكات والتحصيل، وينظّم المسابقات القرآنية من إعداد الأسئلة حتى إعلان النتائج. الواجهة بالكامل بالعربية (RTL).

## المميزات

- **الهيكل التنظيمي:** إدارة المراكز والفروع والحلقات، وإسناد المعلمين والمشرفين للحلقات مع سجل لتاريخ الإسناد.
- **الطلاب:** ملف شامل لكل طالب (بيانات أساسية، تفاصيل الإتقان والإبداع والبناء)، استيراد جماعي من Excel، بحث متقدم، وقائمة مفضلة للمتابعة السريعة.
- **المتابعة التعليمية:** تسجيل الحضور والغياب، المتابعة الأسبوعية للحفظ والمراجعة، خطط الجلسات الجماعية، اختبارات السور، والملاحظات السلوكية.
- **الاشتراكات والتحصيل:** أسعار اشتراكات مرنة، إدارة اشتراكات الطلاب وتحويلها، وجولات تحصيل بسجل متابعة لكل جولة.
- **المسابقات:** إنشاء مسابقات بمستويات وأسئلة، تعيين الممتحنين، تسجيل مشاركين داخليين وخارجيين، بوابة خاصة بالممتحن لإجراء الاختبار، وحساب النتائج وإعلانها.
- **أولياء الأمور:** حسابات لأولياء الأمور وبحث مخصص لمتابعة أبنائهم.
- **التوصيات:** توصيات جاهزة بقوالب قابلة للتخصيص.
- **الصلاحيات والإشعارات:** أدوار وصلاحيات دقيقة لكل مستخدم (مدير، مشرف، معلم، ممتحن...)، ونظام إشعارات داخلي.
- **التقارير:** تصدير PDF وExcel للبيانات والتقارير.

## التثبيت والتشغيل محليًا

```bash
# 1) نسخ المشروع
git clone https://github.com/Muhammed-17/hamaltalquran.git
cd hamaltalquran

# 2) تثبيت الاعتماديات
composer install
npm install

# 3) إعداد البيئة
cp .env.example .env
php artisan key:generate
```

عدّل ملف `.env` بما يناسب بيئتك المحلية، وأهم الإعدادات:

| المتغير                                                   | الوصف                                                                       |
| --------------------------------------------------------- | --------------------------------------------------------------------------- |
| `APP_URL`                                                 | عنوان التطبيق (محليًا: `http://localhost:8000`)                             |
| `DB_HOST` / `DB_DATABASE` / `DB_USERNAME` / `DB_PASSWORD` | بيانات اتصال قاعدة البيانات — أنشئ قاعدة فارغة أولًا                        |
| `ADMIN_INITIAL_PASSWORD`                                  | **مطلوب قبل التهيئة:** كلمة مرور حساب المدير الأول (بدونها يفشل الـ seeder) |

```bash
# 4) إنشاء الجداول وتهيئة البيانات الأساسية والحسابات
php artisan migrate --seed

# 5) بناء الواجهة وتشغيل الخادم
npm run build
php artisan serve
```

بعدها افتح `http://localhost:8000` وسجّل الدخول بحساب المدير.

> ملحوظة: ملف `.env.example` مهيأ افتراضيًا للنشر (إنتاج)، فاضبط `APP_ENV=local` و `APP_DEBUG=true` أثناء التطوير.

## حساب المدير الافتراضي

ينشئ الـ seeder حساب مدير أول:

- **البريد:** `markaz@gmail.com`

غيّر كلمة المرور بعد أول تسجيل دخول. لا توجد صفحة تسجيل عامة في النظام؛ حسابات المستخدمين تُنشأ من داخل لوحة الإدارة.

## الاختبارات

```bash
php artisan test
```

تعمل الاختبارات على قاعدة SQLite مؤقتة في الذاكرة (إعداد `phpunit.xml`) فلا تمس قاعدة بيانات التطوير أو الإنتاج.

## هيكل المشروع باختصار

```
app/
├── Http/Controllers/     # وحدات التحكم (طلاب، حلقات، مسابقات، اشتراكات...)
├── Http/Requests/        # قواعد التحقق من المدخلات
├── Models/               # نماذج البيانات (48 نموذجًا)
resources/views/          # واجهات Blade (عربية RTL)
database/
├── migrations/           # هيكل قاعدة البيانات
└── seeders/              # تهيئة الأدوار والصلاحيات والبيانات الأساسية
routes/                   # مسارات الويب والمصادقة والفروع
tests/                    # اختبارات Pest (Feature و Unit)
```
